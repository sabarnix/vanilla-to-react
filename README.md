# From Vanilla JS to React — A One-Week Course

> Go from absolute beginner to intermediate React developer in 7 days.

## What You'll Learn

This course teaches React the *right* way — by first showing you **why** it exists.

Most React courses throw you straight into JSX and hooks without explaining the problems React was built to solve. This one doesn't.

You'll start by building a real app in plain JavaScript. You'll feel the pain of managing state by hand, syncing the DOM yourself, and watching your code spiral out of control. Then you'll rebuild it in React — and understand *exactly* why every feature exists.

---

## Course Structure

### Week 1 — 7 Days, One Concept at a Time

| Day | Topic | What You Build |
|-----|-------|----------------|
| **Day 1** | HTML, CSS & the DOM | A static to-do list |
| **Day 2** | Vanilla JS — Events & State | Make the to-do list interactive |
| **Day 3** | The Pain — Async & State Management | Add an API call. Feel the chaos. |
| **Day 4** | Why React Exists | Rebuild Day 3's app with React |
| **Day 5** | Components, Props & State | Break your app into reusable pieces |
| **Day 6** | useEffect & Data Fetching | Fetch data the React way |
| **Day 7** | Putting It All Together | Ship a complete React app |

---

## Prerequisites

- Basic understanding of what HTML is
- No JavaScript experience required
- No React experience required
- Just curiosity and a browser

---

## Who This Is For

- **Absolute beginners** who want to learn React but don't know where to start
- **Developers** who know HTML/CSS but haven't touched JavaScript much
- **Self-taught coders** who want a structured path to React

---

## Philosophy

> "You can't appreciate the solution until you've felt the problem."

We don't start with React. We start with the problem React solves.

By the end of Day 3, you'll be frustrated with vanilla JS state management. By Day 4, React will feel like a relief — not a burden.

---

## Getting Started

Each day has its own folder with:
- A **lesson** explaining the concept
- **Starter code** to work from
- A **solution** to check your work

Clone this repo and follow along:

```bash
git clone https://github.com/sabarnix/vanilla-to-react.git
cd vanilla-to-react
```

No build tools needed for Days 1–3. Just open the HTML file in your browser.
